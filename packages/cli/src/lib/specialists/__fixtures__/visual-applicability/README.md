# Visual applicability replay

`visual-craft-director-v2.yaml` preserves the pre-fix contract byte for byte.
`cases.json` contains bounded context inputs and an independent expected outcome.

The coordinator supplies each complete synthetic context and invokes a fresh native
evaluation with the selected contract. Fixture and compiled-instruction hashes are
retained in a local manifest; these are not production mission certifications.
Never include `expected` in the evaluated prompt. Cases intentionally provide no current visual evidence.
The pre-implementation case is a defensive boundary exercise, not a request to
change the specialist's post-implementation-only routing.

For `not-applicable`, require canonical `pass` with explicit rendered-UI N/A,
inspected paths and a concrete no-rendered-change reason in `limitations`. Reject
invented craft scores, screenshots, and claims that visual quality was certified.
For `blocked`, require canonical `blocked`, a concrete limitation and relevant
evidence request; a silent N/A is a failure. Parse all results through the existing
specialist completion validator. Record actual native results separately from
deterministic fixture/contract assertions.

The same fixture inputs are replayed before and after the contract change. A
contract-text test alone cannot prove that the prose changes agent behavior.
