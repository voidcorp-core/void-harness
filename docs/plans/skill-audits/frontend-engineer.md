# Specialist audit: `frontend-engineer`

## Need and boundary

Frontend missions need implementation-structure review for component boundaries, state modeling,
server/client separation, responsive behavior, design-system composition, and browser evidence. The
role does not invent UX or brand, certify craft/accessibility, perform generic QA, or write code.

## Sources and adaptation

React purity, Next.js rendering boundaries, and harness frontend doctrine were distilled without
making one framework mandatory. Self-approval and visual/product ownership were rejected.

## Overlap audit

Experience Designer owns the pre-build brief; Visual Craft Director owns post-build polish;
Accessibility Specialist owns WCAG outcomes. Frontend structure overlaps each by less than 30%.
