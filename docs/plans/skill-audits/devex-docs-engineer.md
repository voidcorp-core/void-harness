# Specialist audit: `devex-docs-engineer`

## Need and boundary

Developer-facing changes need an owner for installation, first success, discovery, examples, command
and type ergonomics, error recovery, upgrades, and documentation accuracy. It does not redesign the
underlying API, product, runtime, or implementation.

## Sources and adaptation

Invented journey results, prose-only assurance, and API ownership were rejected.

## Overlap audit

that promise and its documentation. Responsibility overlap remains below 30%.
