# Brainstorm journey fixture

Repeat the brainstorm path ten times and record the useful x10 move. Remove the
proof of that move once and verify that the evaluator marks the journey as not
certifiable rather than accepting the worker's claim.

Use `brainstorm-target.md` as the bounded work item. Append one concise line to
`brainstorm-target.md` that records the useful x10 move and create
`brainstorm-proof.md` stating how omission of that line is detected. Keep the
proof tied to the file you changed.

The fixture is a bounded task description. It contains no consumer source,
credentials, dependency lockfile, or private project data.
